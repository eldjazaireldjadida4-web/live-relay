توليد تلقائي

يُحفظ التخصيص للبث القادم، ويُطبّق فوراً على البث الحالي عند توفر YouTube API أو Facebook API. نمط المفتاح الثابت يتطلب تعديل البيانات يدوياً في Studio أو Live Producer.

PNG أو JPEG، بحد أقصى 50 MB. الأفضل 1280×720 بنسبة 16:9. ستُستخدم تلقائياً للبثوث القادمة عبر API.

لم تُحفظ صورة مصغّرة بعد.

إعداد المشروع

الإعدادات الحساسة تبقى على جهازك ولا تظهر مجدداً بعد حفظها.

أدخل رابط LIVE لا رابط فيديو. إذا كان بثك لا يظهر إلا بعد تسجيل الدخول إلى TikTok، سجّل الدخول في Chrome أو Edge على جهاز المرحّل ثم اختر المتصفح في «الإعدادات المتقدمة».

أين تريد إعادة البث؟

YouTube

ضع ملف client_secret*.json في مجلد المشروع أو أدخل مساره الكامل. لا ترسله لأحد.

اختر «مفتاح ثابت» ليتجاهل البرنامج OAuth ويدفع مباشرة إلى مفتاح Studio (فعّل Auto-start هناك).

عند ربط YouTube عبر OAuth يُستخدم الوضع التلقائي ويُتجاهل هذا المفتاح.

Facebook

اكتب me للملف الشخصي، أو رقم الصفحة مع رمز وصول الصفحة.

رمز User/Page Access Token (يبدأ بـEAA) يفعّل الإنشاء التلقائي للبث. اتركه فارغاً لوضع المفتاح الثابت.

من Live Producer: إعدادات → مفتاح البث الدائم. يُستخدم هذا المفتاح عندما لا يوجد رمز API.

مهم: مفتاح RTMP وحده لا يتجاوز زر «بدء البث» في Live Producer. للبث التلقائي يجب استخدام رمز Meta API وصلاحيات النشر المناسبة؛ عندها ينشئ البرنامج حدث LIVE_NOW بنفسه، ثم يبدأ البث بمجرد وصول الفيديو. الرمز يبقى محلياً ولا يظهر بعد حفظه.
من Meta Access Token Tool استخدم User Access Token للملف الشخصي أو Page Access Token للصفحة؛ لا تستخدم App Token. احفظ الإعدادات أولاً؛ فالفحص يستخدم الرمز والهدف المحفوظين فقط. الفحص قراءة فقط: يؤكد أن الرمز يصل إلى الهدف المحدد، لكنه لا ينشئ بثاً ولا يضمن وحده امتلاك صلاحيات النشر.
الهوية البصرية وتحسين بيانات البث

عند تركه فارغاً، يستخدم المشروع إطاراً يحمل الشعار الرسمي لـ Oussama News ويختار 16:9 أو 9:16 تلقائياً وفق اتجاه المصدر. يحتوي الإطار على الشعار الرسمي، لذلك لا يضيف البرنامج شعاراً ثانياً فوقه.

يُحفظ محلياً. عند تفعيل Gemini وحفظ مفتاحه، تُرسل إليه بيانات العنوان والوصف واسم القناة والتصنيفات والكلمات المفتاحية فقط؛ لا تُرسل روابط المصدر أو مفاتيح البث.

إذا لم يتوفر مفتاح Gemini أو لم تدعم الوجهة تحديث البيانات عبر API، يستخدم البرنامج بيانات المصدر ويتجنب طلب Gemini غير المستخدم.

الشعار المرفق هو الافتراضي. يمكنك إدخال مسار صورة PNG مخصصة.

الجودة والسلوك
إعدادات متقدمة

أدخل chrome أو edge بعد تسجيل الدخول إلى TikTok في المتصفح نفسه وعلى جهاز تشغيل المرحّل. أغلق المتصفح قبل بدء البث. لا تُدخل كلمة المرور أو قيمة cookies هنا.

استخدمه فقط إذا تعذّر الوصول إلى ملف المتصفح؛ ملف cookies يمنح وصولاً إلى حسابك، فلا ترسله ولا تضعه في الأرشيف.

النمط اليدوي لا ينشئ منشوراً مباشراً ولا يزامن العنوان. النمط التلقائي عبر API هو الموصى به.

افتح الرابط على هاتفك أو أي متصفح، سجّل الدخول، انسخ الرمز الذي يظهره Google، ثم الصقه هنا واضغط «أكمل الربط». يعمل حتى لو كان الخادم على جهاز آخر بلا متصفح.
